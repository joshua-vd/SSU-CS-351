# Project 3 - WebGL Procedural Shapes

## Table of Contents 

 - [My Wireframe Triangle] (triangle.html)

This program uses WebGL shaders to generate a wireframe triangle using gl.LINE_LOOP. 

 - [My Filled Polygon] (polygon.html) 

This version renders a filled 10-sided polygon using gl.TRIANGLE_FAN and shader-generated vertices. 

 - [My Five Pointed Star] (star.html)

This program modifies vertex positions based on gl_VertexID to create a five-pointed star shape. 

 - [My Rotating Star] (rotating-star.html) 

This version animates the start by rotating it over time using a uniform time variable in the vertex shader. 


## Description 

This project uses WebGL shaders to procedurally create simple shapes, including a wireframe triangle, a filled polygon, a star, and a rotating, animated star.
